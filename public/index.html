Plain English Terminology Guide

RPC Node (Remote Procedure Call)

A server that acts as a bridge between your web browser and the blockchain. Without RPC nodes, applications cannot read account balances or send transactions.

EWMA Latency (Exponentially Weighted Moving Average)

A smart metric measuring how fast an RPC node responds in milliseconds (ms). It ignores sudden temporary ping spikes so your router always picks the genuinely fastest server.

MEV Front-Running Shield (Maximal Extractable Value)

When you send transactions publicly, malicious arbitrage bots can jump ahead of your trade ("sandwich attack") to make you pay higher prices. Enabling the **MEV Shield** routes your transaction privately straight to block builders, bypassing public mempools.

Circuit Breaker ("Kill Endpoint")

An emergency safety mechanism. If an RPC node goes offline or returns bad data, clicking "Kill Endpoint" manually disables it, causing the router to immediately send traffic to alternative healthy servers with zero downtime.

State Dry-Run / Simulation

A sandbox rehearsal. It tests your transaction against a copy of the blockchain state to prove it will succeed, showing exact balance changes and gas fees before real money is spent.

Gemini AI Threat Risk & Intent Explainer

Translates unreadable EVM smart contract hex code (e.g. `0xa9059cbb...`) into plain English (e.g., *"Transfer 100 USDC to Alice"*), preventing you from accidentally approving malicious contracts.
